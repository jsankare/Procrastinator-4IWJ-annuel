# Instructions du Projet Vue.js/Nuxt 4

## Consignes Générales

- **Projet libre** : Vous devez réaliser un projet qui couvre l'ensemble des notions abordées pendant le cours
- **Validation préalable** : L'idée de votre projet doit être soumise et validée le plus tôt possible pour garantir sa faisabilité
- **Travail en équipe** : Constituez une équipe de **trois personnes**
- **Livraison** : Le projet doit être envoyé via MyGES **une semaine avant** la date de soutenance
- **Compatibilité** : Le projet réalisé peut être le même que votre projet annuel

## Objectif Général

Réaliser une application web moderne en **Vue.js 3** ou **Nuxt 4**, intégrant :

- ✅ Un design cohérent et responsive
- ✅ Une gestion de données dynamique (API réelle ou mockée)
- ✅ Un espace utilisateur ou un système d'administration simple
- ✅ Une logique métier claire et maîtrisée
- ✅ Un code structuré utilisant de bonnes pratiques Vue

## Éléments Techniques Requis

### Composants et Architecture
- [ ] **Minimum 8 composants Vue réutilisables**
- [ ] **Utilisation correcte** des `props`, `emits`, `v-model`, et éventuellement `defineModel`
- [ ] **Usage de la Composition API** dans plusieurs composants

### Gestion des Données
- [ ] **Appels à une API** (réelle ou mockée)
- [ ] **Utilisation de Pinia** pour la gestion d'état global

### Routing et Navigation
- [ ] **Vue Router** avec des pages dynamiques
  - *(Pour Nuxt : pages automatiques acceptées)*

### Formulaires
- [ ] **Au moins un formulaire** avec :
  - Gestion de la validation
  - Messages d'erreur appropriés

### Fonctionnalités Avancées (2 minimum)
Choisir **au moins 2** parmi :
- [ ] Communication composants enfants → parent via `emits`
- [ ] Watchers / computed élaborés
- [ ] Composables personnalisés
- [ ] Directives personnalisées
- [ ] Slots (simples ou nommés)
- [ ] Lazy loading / code splitting
- [ ] Middleware (si Nuxt)
